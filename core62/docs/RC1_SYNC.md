# RC1 — encrypted journal sync reference
Reference HTTP adapter with injected authenticator, opaque encrypted envelope, per-account revision CAS, last-operation idempotent retry, strict prefix relation and manual divergence block. No automatic merge of conflicting journals. Integration test uses actual localhost HTTP and Node Web Crypto with two synthetic accounts. Memory store is not durable, not production authentication, and not deployed. No cloud credentials or user data accessed. Legacy cloud uses window.claude.use; no independent cloud backend in repository. Production provider, server-side durable CAS, authenticated identity and UI transport integration remain open. Six source-level protocol checks executed; HTTP suite added to existing CI. No main merge.
