# RC1 durable reference backend
SQLite WAL/FULL synchronous and BEGIN IMMEDIATE per CAS, with parameterized per-account access and encrypted envelope only. Node 22 built-in sqlite; no dependencies. Tests use temporary database, close/reopen, two handles, stale revision and isolated account IDs. Actual cloud deployment, authentication provider, HTTPS, CORS policy, quota, backup/monitoring, and UI transport integration remain unconfigured. No production credentials, account data, or deployment. Server adapter is not part of client distribution. Added autosave cancellation guard during initial enable. CI execution pending.
