# Deployable reference runtime
Build clean distribution, set MASARIFI_DIST to output, MASARIFI_DATABASE outside public root, MASARIFI_ACCOUNTS_FILE to private JSON array of {uid,tokenSha256}. Generate high entropy 32-byte random base64url tokens offline, distribute securely, store only SHA-256 digest in private configuration. Run node core62/server/start-runtime.mjs on Node 22 with durable volume, loopback listener behind authenticated TLS reverse proxy. No public file access except verified manifest assets, no secrets bundled. Explicit bearer access is a limited provisioned-account reference, not signup/OIDC/account recovery. Before production: configure actual domain, HTTPS, access/rate limits, monitoring, backups, key rotation and real-device rehearsal. No hosted deployment or credentials created. Tests exercise actual local HTTP, SQLite restart, two accounts and manifest integrity. Main unchanged.
