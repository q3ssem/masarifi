# Pre-RC migration coverage
Explicit-date simple debts (due plan only), tracked installments with no assumed history and simple zero-savings goals now map to clean commands. Goal deadline retains the legacy first-of-month convention. Source file is untouched. The adapter is strict: meaningful metadata including timestamps, notes on debts, wallet links, preferences, automatic/estimated payments, fixed expenses, saved goals without historical date, monthly debt plans, BNPL extensions and other features still block. Legacy due-date projection and monthly allocation semantics are not fully matched; synthetic fixtures validate amounts and explicit dates only. A standard full legacy backup generally remains blocked. Do not launch or imply full migration. 12/12 source assertions passed. No production data touched.
