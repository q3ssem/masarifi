# RC1 explicit sync UI
Same-origin-only HTTP transport, HTTPS except loopback, explicit user clicks and password/token entered per operation, no external network, no auto-sync. GitHub Pages blocked. Compare journals and reject divergence, CAS upload, pull only a strict remote-ahead revision into session after confirmation; local encrypted save separate. Tests route actual localhost HTTP through reference server and use two isolated browser contexts; not a production deployment. CSP changed from no network to same-origin only. Auth provider and hosted durable backend remain unconfigured. No real account or financial data accessed.
